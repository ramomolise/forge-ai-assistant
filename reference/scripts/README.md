# Reference scripts

This directory is reserved for future scripts that help learners install,
verify, back up, secure, roll back, or remove a reviewed setup.

No executable reference script exists yet. A file must not be added here until
its purpose, prerequisites, important actions, security implications,
verification steps, and rollback behaviour are documented and tested.

Future scripts must be readable to a beginner, use secure shell practices where
appropriate, avoid embedded credentials, preserve existing files through
backups, and stop with useful errors when requirements are missing.

Provider authentication and production secret entry must remain manual. A
script must not claim success unless it verifies the result.
