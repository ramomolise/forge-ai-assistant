# Plugin and tool reference material

This directory is reserved for future narrowly scoped plugin and business-tool
material.

No plugin format, tool interface, permission model, or executable capability is
defined here yet. Future material must be based on independently verified
interfaces and must grant only the minimum access required for one documented
task.

Each future plugin or tool must document its inputs, outputs, permissions,
failure behaviour, security implications, verification steps, and rollback
path. It must not contain credentials, production business information, or
broad general-purpose access.
